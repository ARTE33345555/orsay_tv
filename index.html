ℹ️ About Orsay TV 2.6

Universal TV Reviver

Orsay TV is a custom firmware that transforms legacy Samsung Smart TVs (2010-2014) and compatible devices into modern multimedia centers. It includes IPTV support, DLNA media sharing, Wi-Fi Direct connectivity, and much more.

Features:

  • ✅ IPTV Streaming (H.264/H.265 support)
  • ✅ AllShare DLNA Media Server (UPnP compatible)
  • ✅ Wi-Fi Direct (P2P) for Orsay Remote TV
  • ✅ Wake-on-LAN & Wake-on-Wireless-LAN
  • ✅ Voice control via Home Radio Pro
  • ✅ Telegram TV calling support
  • ✅ OTA updates via ARTE_SERVER
  • ✅ Python 3 runtime environment

Supported Devices:

  • Samsung Orsay TVs (2010-2014)
  • Samsung Tizen 1.0 (Modern)
  • LG NetCast & WebOS 1.0
  • Generic embedded Linux systems
